JaneConverter Browser Capture

Capture media from the open, signed-in page. For approved sites, the browser fetches selected media using its own temporary session; JaneConverter receives only media bytes, never cookies.

Experimental: story sequence capture is still being hardened because story viewers change their media codes and layout frequently. It may miss pages or capture duplicates.

Collect mode stays active after this popup closes. Play or advance stories and their primary rendered media is sent to Fetched Media automatically.

Compatibility mode watches only approved media responses from this tab. It never reads or exports cookies, headers, tokens, or page text. Chrome will show a debugger permission warning.

JaneConverter records safe capture diagnostics in its Console: site, media type, response status, size, and fallback reason. It never records cookies, tokens, headers, or signed URLs.
